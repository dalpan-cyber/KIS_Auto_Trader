1단계: 저장소 가져오기 (Fork vs Clone 비교 및 선택)

💡 Fork와 Clone 중 어떤 방식을 선택해야 할까요?
  • 방식 A: GitHub Fork (권장 - 24시간 무인 클라우드 자동매매 구축 시)
    GitHub 웹에서 버튼 한 번으로 본인 계정에 원격 저장소를 복제합니다. GitHub Actions와 Streamlit Cloud가 본인의 GitHub 계정을 바라보아야 하므로, 컴퓨터를 꺼두고 전자동으로 돌리실 분들에게 가장 쉽고 완벽한 방법입니다. 원본 업데이트 시 'Sync fork' 버튼으로 최신 코드 동기화도 클릭 한 번으로 가능합니다.
  • 방식 B: Git Clone (로컬 PC 직접 실행 또는 프라이빗(Private) 저장소 구축 시)
    내 컴퓨터나 개인 홈 서버에서 직접 프로그램을 켜두고 구동할 때 적합합니다. 만약 코드를 비공개(Private)로 유지하면서 클라우드에 올리고 싶다면 로컬로 Clone 후 본인만의 Private 저장소로 Push하여 사용할 수도 있습니다.
구분 방식 A: GitHub Fork (추천 ⭐) 방식 B: Git Clone
주요 목적 내 PC를 끄고 24시간 클라우드 무인 자동매매 내 PC에서 직접 실행 또는 Private 저장소 구축
필요 도구 인터넷 웹 브라우저 (클릭만으로 완료) Git CLI 터미널, Python 로컬 설치
장점 설치 없이 GitHub Actions 및 Streamlit 연동 완료, 원클릭 업데이트 로컬에서 자유로운 코드 수정 및 독립적인 Private 저장소 구성 가능
A[방법 A] GitHub 웹에서 Fork하기 (클라우드 무인 자동화 추천)

1. 인터넷 브라우저로 원본 저장소 주소(https://github.com/chanhongpark/KIS_Auto_Trader)에 접속합니다.

2. 화면 우측 상단에 있는 [Fork] 버튼을 클릭합니다.

3. Create fork 버튼을 누르면 본인 계정에 https://github.com/<본인ID>/KIS_Auto_Trader 저장소가 자동으로 복제됩니다.

B[방법 B] Git Clone으로 로컬 PC에 가져오기 (내 PC 실행용)

1. 내 컴퓨터의 터미널(Git Bash 또는 명령 프롬프트)을 열고 원하는 폴더로 이동합니다.

2. 아래 명령어로 저장소를 복제합니다:

git clone https://github.com/chanhongpark/KIS_Auto_Trader.git
cd KIS_Auto_Trader
pip install -r requirements.txt

3. 로컬 실행 시 프로젝트 루트 폴더에 .env 파일을 생성하여 계좌 키를 설정하고 python app.py로 대시보드를 실행합니다.

2단계: 한국투자증권 Open API 키 발급 & MTS 필수 설정

1KIS Developers 포털 가입 및 앱 등록

1. 한국투자증권 KIS Developers (apiportal.koreainvestment.com)에 접속하여 로그인합니다.

2. 상단 메뉴에서 [오픈API 신청] > [앱 등록/관리]를 클릭합니다.

3. 본인의 실전투자 계좌를 선택하고 앱을 등록합니다.

4. 발급된 AppKey와 AppSecret을 안전한 곳(메모장)에 복사해 둡니다.

2MTS(스마트폰 앱) 필수 거래 신청 (매우 중요!)

무한매수 대상인 미국 3배 레버리지 ETF(TQQQ, SOXL 등)를 매매하기 위해 증권사에 다음 3가지 신청이 필수로 등록되어 있어야 주문 오류가 발생하지 않습니다.

  • 해외주식 거래 신청: MTS > 메뉴 > 안내/신청 > 해외주식 거래 서비스 신청
  • 해외 ETF 거래 신청 및 기본예탁금 등록: MTS > 메뉴 > 안내/신청 > 해외 ETF 거래 신청 (기본예탁금 면제/등록)
  • 레버리지 ETF 교육 이수 등록:
    1. 금융투자교육원 접속 후 '레버리지 ETP(ETF/ETN) 가이드' (1시간 온라인 교육) 수료
    2. 한국투자증권 MTS > 메뉴 > 안내/신청 > '레버리지 ETF 교육이수 등록'에 수료 번호 입력

3단계: Google Sheets & 서비스 계정 생성

1구글 스프레드시트 생성

1. Google Drive에 접속하여 새 스프레드시트를 생성합니다.

2. 스프레드시트 제목을 반드시 KIS_무한매수_매매일지로 입력합니다.

✨ 스마트 자동 워크시트 생성 지원:
최신 시스템에서는 프로그램 실행 시 필요한 시트(CompletedTrades 전량매도일지, Settings 설정동기화, State 회차관리, ExecutionHistory 체결이력, Holdings 보유현황)가 자동으로 생성 및 헤더가 초기화됩니다! 사용자가 일일이 수동으로 탭을 만들지 않아도 제목만 정확히 맞추고 공유하면 됩니다.
2Google Cloud Platform(GCP) 서비스 계정 키 발급

1. Google Cloud Console에 접속하여 새 프로젝트를 생성합니다.

2. [API 및 서비스] > [라이브러리]에서 다음 2개 API를 검색하여 [사용(활성화)]을 클릭합니다:

  • Google Drive API
  • Google Sheets API

3. [API 및 서비스] > [사용자 인증 정보] > [사용자 인증 정보 만들기] > [서비스 계정]을 클릭합니다.

4. 이름(예: kis-sheets-bot)을 넣고 생성을 완료합니다.

5. 생성된 서비스 계정을 클릭 > [키(Keys)] 탭 > [키 추가] > [새 키 만들기] > JSON을 선택하여 키 파일을 다운로드합니다.

6. 다운로드된 JSON 파일을 메모장으로 열어 client_email 값(예: kis-sheets-bot@xxxx.iam.gserviceaccount.com)을 복사합니다.

7. 앞서 만든 구글 스프레드시트(KIS_무한매수_매매일지)의 [공유] 버튼을 누르고, 복사한 서비스 계정 이메일을 편집자 권한으로 초대합니다.

4단계: GitHub Actions Secrets 등록 & 권한 설정

1GitHub Actions 쓰기 권한 활성화 (필수)

자동매매가 끝난 후 진행 회차(예: 6.0회차) 및 설정 파일(infinite_trader_state.json, infinite_settings.json)을 Git에 자동 커밋/저장하기 위해 권한이 필요합니다.

1. 본인 GitHub 저장소 > [Settings] > [Actions] > [General]로 이동합니다.

2. 화면 맨 아래 Workflow permissions 섹션에서 [Read and write permissions]를 체크하고 Save를 클릭합니다.

2GitHub Repository Secrets 등록

본인 저장소 > [Settings] > [Secrets and variables] > [Actions] > [New repository secret]을 눌러 다음 항목들을 등록합니다.

Secret 이름 (정확히 입력) 설명 입력 값 예시
KIS_APP_KEY 한국투자증권 AppKey PSxxxxxxxxxxxxxx
KIS_APP_SECRET 한국투자증권 AppSecret xxxxxxxxxxxxxxxxxxxxxxxx
KIS_CANO 계좌번호 앞 8자리 12345678
KIS_ACNT_PRDT_CD 계좌상품코드 2자리 01
KIS_ACCOUNT_PWD 계좌 비밀번호 4자리 1234
GCP_SERVICE_ACCOUNT_JSON GCP 서비스 계정 JSON 전체 내용 JSON 파일 내용 전체 복사 ({...})

5단계: Streamlit Cloud 무료 웹 대시보드 배포

1Streamlit Cloud 앱 생성

1. share.streamlit.io에 접속하여 GitHub 계정으로 로그인합니다.

2. 우측 상단의 [Create app]을 클릭합니다.

3. 저장소 정보를 입력합니다:

  • Repository: 본인의 저장소 (예: <본인ID>/KIS_Auto_Trader)
  • Branch: main
  • Main file path: app.py

4. [Advanced settings...] 버튼을 클릭합니다.

2Streamlit Secrets 환경변수 입력

Advanced settings 창의 Secrets 입력창에 아래 내용을 그대로 복사하고 본인의 정보로 채워 넣습니다:

KIS_APP_KEY = "발급받은_AppKey"
KIS_APP_SECRET = "발급받은_AppSecret"
KIS_CANO = "계좌번호앞8자리"
KIS_ACNT_PRDT_CD = "01"
KIS_ACCOUNT_PWD = "계좌비밀번호4자리"
MOCK_TRADING_ONLY = "false"

# [선택사항] 메신저 알림 연동
# DISCORD_WEBHOOK_URL = "https://discord.com/api/webhooks/..."
# TELEGRAM_BOT_TOKEN = "123456:ABC-DEF..."
# TELEGRAM_CHAT_ID = "123456789"

# GCP 서비스 계정 키 JSON
GCP_SERVICE_ACCOUNT_JSON = '''
{
  "type": "service_account",
  "project_id": "your-project-id",
  "private_key_id": "...",
  "private_key": "-----BEGIN PRIVATE KEY-----\n...\n-----END PRIVATE KEY-----\n",
  "client_email": "kis-sheets-bot@your-project-id.iam.gserviceaccount.com",
  "client_id": "...",
  "auth_uri": "https://accounts.google.com/o/oauth2/auth",
  "token_uri": "https://oauth2.googleapis.com/token"
}
'''

5. [Save] 후 [Deploy!] 버튼을 누르면 1~2분 뒤 나만의 모바일/웹 대시보드가 오픈됩니다!

6단계: 자동매매 스케줄 및 동작 검증

1최신 자동 실행 시간표 (한국 시간 KST 기준)

최신 시스템 스크립트(run_infinite_buying.py)는 시간대를 지능적으로 감지하여 작동합니다:

  • 밤 22:35 (월~금, 미국 서머타임 기준): 미국 정규장 개장 직후 평단가 LOC 매수 + 상향 LOC 매수 + +10% 지정가 익절 매도 자동 발주 (서머타임 미적용 시 밤 23:35)
  • 아침 06:05 (화~토): 미국 장 마감 직후 체결 결과 확인, 회차 자동 전진/리셋, Google Sheets 및 Git 저장소 자동 백업 동기화 (신규 주문 미발주 모드)
2수동 즉시 실행 테스트 (정상 작동 확인)

GitHub Actions가 잘 작동하는지 지금 바로 테스트해 볼 수 있습니다:

1. 본인 GitHub 저장소 > [Actions] 탭으로 이동합니다.

2. 좌측에서 `🇺🇸 KIS 라오어 무한매수법 무인 자동매매` 워크플로우를 선택합니다.

3. 우측 [Run workflow] 드롭다운을 누르고 초록색 [Run workflow] 버튼을 클릭합니다.

4. 1분 후 초록색 체크(✔)가 뜨고 실행 로그에 잔고와 주문 제안이 정상 출력되면 모든 세팅이 완벽하게 끝난 것입니다!

🛡️ 40회차 소진 시 대응 옵션 안내 (대시보드에서 종목별 맞춤 설정 가능)
주가가 하락하여 40회차까지 모두 소진되었을 때 대시보드의 [🇺🇸 라오어 무한매수] 탭에서 종목별로 다음 대응 옵션을 자유롭게 설정할 수 있습니다:
  1. AUTO (지능형 자동 대응 - 기본 권장): 시장 상황 및 평단가에 맞춰 유연하게 대처
  2. QUARTER (쿼터 순환 매매): 매일 1회차 분량을 매도하고 LOC 재매수하여 평단가를 강제로 인하
  3. HOLD (무한 대기): 추가 매수를 중단하고 원금을 보존하며 +10% 익절 매도만 유지
  4. LOWER_ROI (목표수익률 하향): 40회차 도달 시 목표 수익률을 +5% 등으로 자동 낮춰 조기 탈출 유도
